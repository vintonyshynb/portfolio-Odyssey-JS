# 🚀 Odyssey JS

A simple 3D space game built with **Three.js**, where you control a spaceship and avoid incoming asteroids.

## 🎮 Gameplay

* Move your spaceship using:

  * `W / A / S / D` or Arrow Keys
  * Left and Right mouse click it's Attack
* Avoid asteroids
* Score increases over time
* Press `R` to restart after Game Over

## ✨ Features

* 🌌 Procedural starfield background
* ☄️ Random asteroid spawning
* 💥 Explosion particle effects
* 📈 Dynamic difficulty scaling
* 🎥 Screen shake on collision
* ⚡ FPS counter
* 🧑 Game with friend

## 🛠️ Technologies Used

* JavaScript (ES6 Modules)
* Three.js
* WebGL

## 📦 Installation

1. Clone the repository:

```bash
git clone https://github.com/vintonyshynb/portfolio-Odyssey-JS.git
cd Odyssey-JS
```

2. Install dependencies:

```bash
npm install
```

3. Run locally (important for GLTF loading):

```bash
npx vite
```

OR use any local server:

```bash
npx serve
```

## 📁 Assets Required

Make sure these files are in the root directory:

* `spaceship.glb`
* `plaggy_cc0-ufo-621.glb`
* `quaternius_cc0-spaceship-1367.glb`
* `explosion.mp3`
